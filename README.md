# Socure front-end assessment
Implementation of the Socure front-end dev test using React, TypeScript, and Vite.  Deployed on GitHub pages here: https://isierra2694.github.io/socure-exercise/

## Getting started
### Install dependencies
```bash
npm install
```

### Start the development server
```bash
npm run dev
```
The application should be hosted at the URL shown in the terminal, typically `http://localhost:5173`.

## Build
```bash
npm run build
```
Deployment to GitHub pages is handled automatically through the GitHub actions workflow whenever changes are made to `master`.
